# Roadmap to the replacement OS

The active target is the complete Pixel 9a OS, not another standalone launcher
iteration. Minimal monochrome presentation remains a preference; cosmetic work
is paused while framework/product integration and compilation advance. MCP is
deferred.

| Stage | Work | Exit evidence |
|---|---|---|
| 1 — Pinned OS integration | Gesture kernel, DisplayPolicy observer, source-built AIHome product, initial HOME-role/resources and three canonical patches | Synthetic tests and exact changed-file patch regeneration; explicitly not a full framework/Soong build |
| 2 — Complete development inputs | Suitable compilation runner, authenticated full source import, coherent factory/kernel/vendor set, actual vendor/dependency generation and reviewed content inventory | Complete prepared tree and input artifacts pass exact verification; capture alone does not approve generated bytes |
| 3 — Development OS compile | Explicit source-only development lock and `userdebug` build wrapper | Actual target-files/OS artifacts with source/build provenance; no production key or live update service required |
| 4 — Dev Pixel OS validation | Separately approved exact-image procedure; verify boot, Home, native apps, recovery and official ChatGPT | Recorded physical results, including default-off gesture enablement, partial ChatGPT touch effects, locks/calls and normal navigation |
| 5 — Production release proof | Own signing identity/updater, `user` build, physical verified boot, OTA/recovery/rollback tests, security coverage | Reviewed signed release evidence and sustainable upstream-update ownership |

Current source work includes the 239-assertion synthetic recognizer and product/
framework patches against selected hash-pinned GrapheneOS `2026100600` files.
No complete source sync, factory archive verification, vendor generation, full
Soong build, boot or flash has been completed. The 16 GiB RAM / roughly 29 GiB
disk workspace cannot compile the full OS. See the
[OS integration guide](os-integration.md) and [development setup](development.md).

The gesture observer defaults off via `aifirst_shape_gestures_enabled`.
Triangle opens the dialer and square opens default Messages with one finger,
without an edge hold. Touches still reach ChatGPT and may scroll/select before
the handoff. Source tests do not establish safe or reliable physical input
behavior.

The [earlier APK quickstart](pixel-quickstart.md) is a historical component
harness, not the current full-OS build or installation procedure. A previous APK
pass does not validate the new framework, product-role grants or OS image.

Any device installation procedure must identify exact artifacts, model, data-loss
risk, signing/bootloader constraints, backups and compatible recovery. No build
or source publication authorizes an unlock, wipe, flash or relock.
